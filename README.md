# 🛒 Task 7: Sales Summary using SQLite & Python

This project analyzes a small sales dataset stored in an SQLite database using Python. It summarizes total quantity and revenue per product, identifies the best-selling item, and visualizes results.

## 🚀 Tools Used
- Python
- SQLite (sqlite3)
- pandas
- matplotlib

## 📌 Key Features
- Connects to `sales_data.db`
- Runs 3 SQL queries:
  - Total quantity and revenue per product
  - Best-selling product by quantity
  - Top revenue-generating product
- Displays results using print and a simple bar chart

## 📊 Output
- Printed summary table
- Bar chart of revenue by product (`sales_chart.png`)

## 🧠 Concepts Used
- SQL with Python
- GROUP BY, SUM, ORDER BY, LIMIT
- Data visualization with matplotlib
